# SUMO Traffic Simulation

## Overview

This project implements a SUMO-based traffic simulation for a 5×5 urban road network and provides a Gymnasium-compatible reinforcement learning environment through the TraCI interface.

The system is designed as the foundation for intelligent traffic signal control using PPO.

## City Configuration

- Grid: 5×5
- Intersections: 25
- Cell size: 100 m × 100 m
- Roads: 1 lane per direction
- Road speed limit: 13.9 m/s

## Simulation Configuration

- Simulation duration: 1 hour (3600 seconds)
- Timestep: 1 second
- Random seed: 42
- Traffic demand: 600 vehicles/hour

## Vehicle Types

| Vehicle | Demand | Maximum Speed |
|---|---:|---:|
| Car | 420 veh/h | 13.9 m/s |
| Bus | 90 veh/h | 13.9 m/s |
| Truck | 90 veh/h | 13.9 m/s |
| **Total** | **600 veh/h** | |

## Traffic Lights

Traffic lights are generated by SUMO using static signal programs.

- Green phase: 30 seconds
- Yellow phase: 3 seconds
- Traffic signal phases control the North-South and East-West movements.
- TraCI is used to read and control traffic-light phases.

## TraCI Data Collection

The simulation collects the following traffic observations:

- Queue length
- Waiting time
- Average speed
- CO₂ emissions
- Current traffic-light phase
- Phase elapsed time

Additional evaluation metrics include:

- Waiting time
- CO₂ emissions
- Average speed
- Queue length
- Throughput

## Reinforcement Learning Environment

A Gymnasium-compatible environment is implemented in:

`environment/traffic_env.py`

### Actions

- `0` — Keep current traffic-light phase
- `1` — Switch to the next traffic-light phase

### Observations

The environment provides six observations:

1. Queue length
2. Total waiting time
3. Average speed
4. CO₂ emission
5. Current traffic-light phase
6. Phase elapsed time

### Reward

The reward is based on a weighted traffic cost:

- Waiting time: `0.5`
- CO₂ emission: `0.3`
- Queue length: `0.2`

Lower waiting time, emissions and queue length produce a better reward.

### Episode

Each RL episode is limited to 3600 seconds (1 hour).

## Output

Traffic simulation data is stored in JSON format.

The output contains traffic observations, traffic-light information and emission-related data.
